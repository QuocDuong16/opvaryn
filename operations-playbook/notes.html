Sổ tay ý tưởng & ghi chú riêng

Đây là phần dành cho bạn tiếp tục bổ sung, lưu những quyết định mới và bảo toàn ngữ cảnh dự án khi ý tưởng ngày càng mở rộng.

Trang này hỗ trợ ghi chú cá nhân theo từng chủ đề, lưu tự động trong trình duyệt. Có thể thêm ý tưởng riêng, xuất/nhập một file JSON để sao lưu hoặc chuyển máy. Nếu mở file qua file://, một số trình duyệt có chính sách lưu khác nhau: hãy xuất bản sao thường xuyên.

Xuất JSON gồm các ô ghi chú, ý tưởng mới, checklist và trạng thái quyết định. File HTML chứa nội dung gốc, JSON chỉ chứa phần bạn chỉnh sửa.

Tạo bản sao trước khi chuyển máy, xóa cache, thay trình duyệt hoặc cài lại hệ điều hành. Import sẽ thay thế dữ liệu hiện có.
